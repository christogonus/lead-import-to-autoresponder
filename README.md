# Lead Import

## Integration references

### beehiiv

- [Create subscription](https://developers.beehiiv.com/api-reference/subscriptions/create) — `POST /v2/publications/{publicationId}/subscriptions`, used to push contacts
- [List publications](https://developers.beehiiv.com/api-reference/publications/index) — `GET /v2/publications`, the destinations a list can be sent to
- [Rate limiting](https://developers.beehiiv.com/welcome/rate-limiting) — 180 requests per minute per organization
